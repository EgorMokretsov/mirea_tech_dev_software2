# Минимальный калькулятор

Учебный проект для практической работы по CI/CD.
Версия: 1.0.0.

## Возможности

- add(a, b) — сложение двух чисел.
- multiply(a, b) — умножение двух чисел.

## Требования

Python 3.12. Дополнительные библиотеки не требуются.

## Запуск

```bash
python main.py
```

## Тестирование

```bash
python -m unittest discover -s tests -v
```

В проекте шесть unit-тестов: сложение и умножение
положительных чисел, работа с отрицательными числами и нулём.

## CI/CD

GitHub Actions запускается при отправке коммитов во все ветки
и при создании или обновлении Pull Request в main.

Workflow выполняет тесты, генерирует HTML-документацию
из описаний в main.py и сохраняет её в артефакте documentation.

Для PR из development настроено автоматическое слияние
после успешных проверок.

## Ветки

- main — основная ветка.
- development — разработка функций.
- release — подготовка версии к выпуску.
